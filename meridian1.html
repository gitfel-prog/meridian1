✕ FRED API — бесплатный

3. My Account → API Keys → Request API Key
4. Скопируй ключ и вставь ниже.

CB Rate / Ставка ЦБ
CB Rate — Ставка центрального банка
Ключевая процентная ставка ЦБ. Чем выше ставка базовой валюты по сравнению с котируемой — тем сильнее давление вверх на пару. Повышение ставки обычно поддерживает валюту, снижение — давит.
— — ⚫
Rate Diff / Дифференциал
Rate Differential — Дифференциал ставок
Разница между ставками двух ЦБ (Баз − Кот). Положительный дифференциал в пользу базовой валюты исторически поддерживает пару. Рынок реагирует не на уровень, а на изменение дифференциала.
авто — — — ⚫
CB Decision / Решение ЦБ×1.6
CB Decision — Решение центрального банка
Итог заседания ЦБ: повышение, снижение или удержание ставки. Имеет коэффициент ×1.6 из-за высокой рыночной значимости. Риторика протокола (hawkish/dovish) влияет не меньше самого решения.
— — ⚫
Market Expectations / Ожидания рынка
Market Expectations — Рыночные ожидания
Вероятность изменения ставки, заложенная в фьючерсы (OIS, Fed Funds Futures). Отражает коллективный прогноз рынка. Резкое смещение ожиданий вызывает волатильность независимо от фактического решения ЦБ.
— — ⚫

CPI YoY / ИПЦ г/г×1.5
CPI YoY — Инфляция (год к году)
Главный индикатор инфляции. Высокая инфляция → ЦБ повышает ставки → укрепление валюты. Выход выше консенсуса — бычий сигнал. CPIAUCSL в FRED.
 — — ⚫
Core CPI / Базовый ИПЦ
Core CPI — Базовая инфляция
CPI без еды и энергии. Более устойчивый тренд. ФРС и ЕЦБ ориентируются прежде всего на базовый CPI при решениях по ставке.
 — — ⚫
GDP QoQ / ВВП кв/кв×1.3
GDP QoQ — Рост ВВП (квартал к кварталу)
Показатель экономического роста. Выход выше ожиданий поддерживает валюту. Выходит раз в квартал (первая, вторая и финальная оценки). GDP в FRED.
 — — ⚫
NFP / Занятость×1.4
NFP — Non-Farm Payrolls
Ключевой индикатор рынка труда США. Первая пятница месяца. Выход выше консенсуса → ФРС держит ставки → бычий USD. PAYEMS в FRED.
 — — ⚫
Unemployment / Безработица×1.15
Unemployment Rate — Уровень безработицы
Обратный индикатор занятости. Снижение ниже консенсуса — бычий сигнал. Запаздывающий индикатор. UNRATE в FRED.
 — — ⚫
PMI Mfg / Производств. PMI×1.25
Manufacturing PMI
>50 = рост, <50 = сжатие. Опережающий индикатор. ISM Mfg для США.
 — — ⚫
PMI Svc / Сфера услуг PMI×1.25
Services PMI
Деловая активность в секторе услуг (70%+ ВВП). ISM Services для США. Сильнее влияет на валюту, чем производственный PMI.
 — — ⚫
AHE / Ср. почасовой заработок×1.1
Average Hourly Earnings
Выходит с NFP. Рост зарплат → инфляция → жёсткая ДКП → поддержка валюты.
 — — ⚫

10Y Yield / Доходность 10Y
10Y Treasury Yield
Эталонная «безрисковая» ставка. Рост доходностей → капитал притекает → валюта крепнет. Обновляется ежедневно через FRED (DGS10).
 — — — ⚫
10Y Spread / Дифференциал 10Y
10Y Yield Spread
Разница доходностей 10Y (Баз − Кот). Положительный спред поддерживает базовую валюту через carry trade.
 авто — — ⚫
2Y Yield / Доходность 2Y
2Y Treasury Yield
Наиболее чувствительна к ожиданиям по ставке ЦБ. Опережает решения ФРС/ЕЦБ. DGS2 в FRED.
 — — — ⚫
Real Rate / Реальная ставка
Real Interest Rate
Номинальная ставка ЦБ минус инфляция CPI. Рост реальной ставки = сильный бычий сигнал для валюты.
 авто — — ⚫
Yield Curve / Кривая доходности
Yield Curve (2Y10Y)
10Y − 2Y. Инверсия = риск рецессии → медвежий долгосрочно. Авто = 10Y − 2Y.
